# 🌞 Estilo Libre - Colonia de Vacaciones

Sitio web desarrollado para **Estilo Libre**, una colonia de vacaciones.

El proyecto busca presentar de forma clara y accesible la información principal de la colonia: historia, horarios, aranceles, ubicación, documentación y medios de contacto.

## 🌐 Demo

Próximamente disponible online mediante GitHub Pages.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Diseño responsive

## ✨ Características

- Menú de navegación responsive
- Diseño adaptado a dispositivos móviles
- Sección de presentación de la colonia
- Historia de Estilo Libre
- Información de horarios y turnos
- Aranceles
- Integración con Google Maps
- Acceso a documentación y planillas
- Enlaces de contacto mediante WhatsApp, Instagram y correo electrónico

## 📱 Responsive Design

El sitio fue desarrollado para adaptarse tanto a computadoras como a dispositivos móviles.

## 🎯 Objetivo del proyecto

Este proyecto fue realizado como parte de mi formación en Desarrollo Web Full Stack y me permitió aplicar conceptos de:

- Estructura semántica con HTML
- Flexbox y organización de layouts
- Diseño responsive
- Variables CSS
- Navegación móvil
- Integración de contenido multimedia
- Manipulación básica del DOM con JavaScript
